01 · ¿Qué es Markdown?

Texto plano con superpoderes

Markdown es un lenguaje de marcado ligero creado en 2004 por John Gruber. Permite escribir texto con formato usando caracteres simples — sin botones, sin menús, sin ratón.

✍ Texto plano

Un archivo Markdown es texto puro (.md). Funciona en cualquier editor, sistema operativo y se puede leer perfectamente incluso sin renderizar.

🤖 Idioma de la IA

Los modelos de lenguaje (GPT, Claude, Gemini) fueron entrenados con millones de documentos en Markdown. Por eso lo usan por defecto al generar contenido estructurado.

⚡ Convierte a todo

Un mismo archivo .md puede convertirse a Word, PDF, HTML, PowerPoint, EPUB y más formatos con Pandoc, sin perder la estructura.

📂 El estándar de facto

GitHub, Notion, Obsidian, Confluence, Reddit, Discord y prácticamente toda plataforma tecnológica usa Markdown como formato nativo.

🔑 La conexión con la IA: Cuando usas el marco R-C-T-F-R y pides al agente "formato Markdown", obtienes un documento estructurado listo para convertir a Word con un solo comando de Pandoc. Eso es lo que aprenderás en este módulo.

¿Por qué no escribir directamente en Word?

❌ Flujo tradicional

  1. Pides al agente que redacte
  2. La IA responde en texto con formato visual
  3. Copias a Word → el formato se rompe
  4. Pasas 20 minutos arreglando estilos y sangrías
  5. Repites el proceso si cambias algo

✅ Flujo con Markdown + Pandoc

  1. Pides al agente "responde en Markdown"
  2. La IA responde con formato perfecto
  3. Guardas como documento.md
  4. Ejecutas un comando Pandoc
  5. Tienes el .docx con estilos correctos en segundos

El YAML Front Matter es el encabezado de metadatos de un documento Markdown. Va entre tres guiones --- al inicio del archivo. Pandoc lo usa para el título, autor, fecha y opciones de formato del documento final.

✓ Pandoc lee el Front Matter automáticamente y lo convierte en la portada del Word o en los metadatos del PDF, con título centrado, autor y fecha en el formato que espera cada plantilla corporativa.

04 · Pandoc

El conversor universal de documentos

Pandoc convierte entre más de 50 formatos de documentos. Es gratuito, open source y corre desde la terminal con un comando. Una vez instalado, conviertes Markdown a Word en 2 segundos.

Instalación en Windows

1
Método 1: Instalador oficial (recomendado)

Ve a pandoc.org/installing.html → descarga el instalador pandoc-X.X-windows-x86_64.msi → ejecútalo → Next → Finish.

2
Método 2: winget (si tienes Windows 11+)
winget install JohnMacFarlane.Pandoc
3
Verifica la instalación

Abre PowerShell o CMD y escribe:

pandoc --version # Deberías ver: pandoc X.X.X
4
Para generar PDF instala también MiKTeX (opcional)

Descarga desde miktex.org/download. Solo necesario para PDF. Para Word (.docx) no hace falta.

Tu primer documento Word

A
Crea un archivo .md

Abre el Bloc de notas (o VS Code), pega el Markdown que generó la IA y guárdalo como mi_documento.md

B
Abre PowerShell en esa carpeta

En el Explorador de Windows, navega a la carpeta del archivo → mantén pulsado Shift + clic derecho → "Abrir ventana de PowerShell aquí"

C
Ejecuta Pandoc
pandoc mi_documento.md -o mi_documento.docx

En segundos aparece mi_documento.docx en la misma carpeta.

Gratis Open Source Pandoc es completamente gratuito y open source. No requiere registro ni suscripción.

05 · Conversiones

De Markdown a cualquier formato

Un documento Markdown bien escrito se convierte a cualquier formato con un solo comando. Aquí los más útiles para la gestión universitaria.

📄 Word (.docx)

El más usado en universidades. Mantiene todos los estilos, tablas, listas y headings de forma perfecta.

# Conversión básica pandoc doc.md -o doc.docx # Con plantilla corporativa pandoc doc.md \ --reference-doc=plantilla_uni.docx \ -o doc.docx # Con tabla de contenidos automática pandoc doc.md \ --toc --toc-depth=3 \ -o doc.docx

📕 PDF

PDF de alta calidad, ideal para documentos formales, informes y certificados. Requiere LaTeX instalado.

# PDF estándar pandoc doc.md -o doc.pdf # PDF con XeLaTeX (mejor para español) pandoc doc.md \ --pdf-engine=xelatex \ -V lang=es \ -V geometry:margin=2.5cm \ -o doc.pdf # PDF con fuente personalizada pandoc doc.md \ --pdf-engine=xelatex \ -V mainfont="Georgia" \ -o doc.pdf

🌐 HTML

Para publicar en la web, intranet o enviar por correo como página web. No requiere ninguna dependencia extra.

# HTML simple pandoc doc.md -o doc.html # HTML completo (con <!DOCTYPE>, CSS, etc.) pandoc doc.md --standalone -o doc.html # HTML con estilos personalizados pandoc doc.md \ --standalone \ --css=mi_estilo.css \ -o doc.html # HTML con tabla de contenidos pandoc doc.md \ --standalone --toc \ -o doc.html

📊 PowerPoint (.pptx)

Convierte Markdown a diapositivas. Cada # es una diapositiva nueva. Funciona con plantillas .pptx.

# PPT básico (cada # = nueva diapositiva) pandoc doc.md -o presentacion.pptx # Con plantilla corporativa pandoc doc.md \ --reference-doc=plantilla.pptx \ -o presentacion.pptx

📚 Múltiples archivos → 1 doc

Combina todos los .md de una carpeta en un único documento Word o PDF. Perfecto para manuales o programas curriculares.

# Combinar todos los .md en orden pandoc capitulo1.md capitulo2.md \ capitulo3.md -o libro.docx # Con glob (todos los .md de la carpeta) pandoc *.md -o documento_completo.docx # Especificando el orden con un archivo lista pandoc $(cat lista_archivos.txt) \ -o manual_completo.docx

✉ Con plantilla corporativa

La clave para documentos institucionales: crea una vez la plantilla .docx con los estilos de tu universidad y úsala siempre.

# CÓMO CREAR LA PLANTILLA: # 1. Abre Word → aplica tus estilos # (fuentes, colores, márgenes, logo) # 2. Guarda como "plantilla_UNI.docx" # 3. Úsala en Pandoc: pandoc informe.md \ --reference-doc=plantilla_UNI.docx \ -o informe_final.docx # Pandoc preserva tus estilos H1, H2, H3, # Normal, Table, etc. de la plantilla
🚀 Automatización: puedes combinar Pandoc con un script de PowerShell para convertir automáticamente todos los .md de una carpeta. Ideal para generar reportes mensuales con un solo doble clic. Ver ejemplo de script →

Script de conversión automática (Windows PowerShell)

# Guarda este script como "convertir.ps1" # Clic derecho → Ejecutar con PowerShell $carpeta = "C:\Documentos\Informes_Markdown" $salida = "C:\Documentos\Informes_Word" $plantilla = "C:\Plantillas\plantilla_UNI.docx" # Crea la carpeta de salida si no existe New-Item -ItemType Directory -Force -Path $salida | Out-Null # Convierte todos los .md a .docx Get-ChildItem -Path $carpeta -Filter "*.md" | ForEach-Object { $entrada = $_.FullName $nombre = $_.BaseName + ".docx" $destino = Join-Path $salida $nombre pandoc $entrada --reference-doc=$plantilla -o $destino Write-Host "✓ Convertido: $($_.Name) → $nombre" } Write-Host "`n¡Conversión completada! Archivos en: $salida"
06 · Marco R-C-T-F-R

Pedir documentos Markdown con el marco R-C-T-F-R

La combinación perfecta: usa el marco R-C-T-F-R para que el agente genere exactamente el documento que necesitas, ya en formato Markdown listo para Pandoc.

R
Rol — ¿Quién es el agente?

«Eres el coordinador académico de una universidad pública con experiencia en diseño de talleres de formación docente.»

C
Contexto — ¿Cuál es la situación?

«La dirección académica necesita una propuesta formal para un taller de 6 horas dirigido a 30 docentes de nivel secundario sobre herramientas de IA generativa.»

T
Tarea — ¿Qué debe hacer?

«Redacta la propuesta completa del taller incluyendo: resumen ejecutivo, objetivos, cronograma de sesiones con tabla, requisitos técnicos y criterios de evaluación.»

F
Formato — ¿Cómo debe presentarse?

«Responde en formato Markdown con YAML Front Matter al inicio (title, author, date). Usa # para secciones numeradas, ## para subsecciones, tablas Markdown para el cronograma y negritas para términos clave.»

R
Restricciones — ¿Qué NO debe hacer?

«No inventes nombres de docentes ni instituciones reales. No incluyas presupuesto (es sección separada). Máximo 4 páginas A4. Usa lenguaje formal pero no excesivamente técnico.»
