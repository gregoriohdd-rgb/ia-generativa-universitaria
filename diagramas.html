01 · Herramientas

Las 5 herramientas que necesitas conocer

Cada herramienta tiene un punto fuerte. Las de texto (Mermaid, PlantUML) se integran con Markdown y la IA puede generarlas. Las visuales (Draw.io) no requieren aprender sintaxis.

📊
MermaidGratisEn el navegador

Diagramas desde texto en Markdown. Funciona en GitHub, GitLab, Notion, Obsidian y muchas plataformas. Claude y ChatGPT generan código Mermaid excelente con un solo prompt.

  • Flowcharts, secuencia, Gantt, Mindmap, ER
  • Integrado en GitHub README directamente
  • Editor oficial en mermaid.live
  • Plugin para VS Code, Obsidian, Confluence
→ mermaid.live
🌿
PlantUMLGratisJava requerido

El estándar para diagramas UML técnicos en ingeniería de software. Sintaxis más compleja que Mermaid pero más potente para diagramas de clase, secuencia y arquitectura.

  • Diagramas UML: clase, secuencia, estado, caso de uso
  • Diagramas C4 de arquitectura de software
  • Editor online en plantuml.com
  • Integración con IntelliJ, Eclipse, VS Code
→ plantuml.com
🔷
Draw.ioGratisSin login

El Canva de los diagramas. Interfaz visual drag-and-drop, sin cuenta necesaria, guarda en Google Drive. Formato .drawio es XML que la IA puede generar y editar directamente.

  • Interfaz visual: arrastra y suelta formas
  • Integración con Google Drive y Confluence
  • Exporta a PNG, SVG, PDF, XML
  • Extension para VS Code (edita .drawio en el IDE)
→ app.diagrams.net
🧠
Mind Maps IAGratis / Freemium

Mapas mentales generados por IA en segundos. Herramientas como Napkin AI, Miro AI, Coggle y la función mindmap de Mermaid crean mapas completos desde un párrafo de texto.

  • Napkin AI: sube texto → genera diagramas automáticamente
  • Coggle: mapas mentales colaborativos en el navegador
  • Mermaid mindmap: desde código en Markdown
  • Miro AI: tablero con IA incorporada
→ napkin.ai (IA automática)
🗂
Editor XML/SVGGratisEn el navegador

Draw.io guarda los diagramas como XML. Con la IA puedes generar ese XML directamente y pegarlo. También puedes editar diagramas SVG con VS Code o herramientas online.

  • Pide al agente: "genera el XML para Draw.io de este proceso"
  • Pega el XML en Extras → Edit Diagram en Draw.io
  • Exporta a SVG para incrustar en Word o presentaciones
  • XML Editor online: xmlgrid.net
→ xmlgrid.net
02 · Mermaid

Mermaid: diagramas en texto

Mermaid usa una sintaxis simple. Escribes las relaciones en texto y la herramienta genera el diagrama automáticamente. La IA puede generar este código por ti.

Código Mermaid

flowchart TD A([📋 Inicio]) --> B{¿Tiene cuenta?} B -->|Sí| C[Iniciar sesión] B -->|No| D[Registrarse] D --> E[Verificar email] E --> C C --> F([✅ Acceso al sistema])

Sintaxis: TD=arriba-abajo, LR=izquierda-derecha. Nodos: []=rectángulo, {}=rombo (decisión), ([])=óvalo

Vista previa

flowchart TD
  A([📋 Inicio])
     ↓
  B{¿Tiene cuenta?}
   /         \
Sí            No
  ↓            ↓
C[Iniciar]  D[Registrar]
              ↓
           E[Verificar]
              ↓
  ←←←←←←←←←←
     ↓
  F([✅ Acceso])

03 · PlantUML

PlantUML: el estándar UML técnico

PlantUML es más potente que Mermaid para diagramas UML estrictos. Ideal para cursos de ingeniería de software, arquitectura de sistemas y bases de datos.

Código PlantUML

@startuml actor Profesor participant "Sistema SIGA" as SIGA database "BD Académica" as DB Profesor -> SIGA: Ingresa calificaciones SIGA -> DB: Guarda calificaciones DB --> SIGA: Confirmación SIGA -> SIGA: Calcula promedio SIGA --> Profesor: Reporte generado Profesor -> SIGA: Cierra acta SIGA -> DB: Acta firmada @enduml

Cómo ejecutarlo

Opción 1 · Online (más fácil)
1. Ve a plantuml.com/plantuml/uml/
2. Pega el código y renderiza

Opción 2 · VS Code
1. Instala la extensión "PlantUML"
2. Abre un archivo .puml
3. Alt+D para previsualizar

Opción 3 · Con Java local
java -jar plantuml.jar diagrama.puml

04 · Draw.io / diagrams.net

Draw.io: el editor visual definitivo

Draw.io es completamente gratuito, sin cuenta, funciona en el navegador y guarda en Google Drive. También puedes pedirle a la IA que genere el XML del diagrama y pegarlo directamente.

Uso visual (sin código)

  1. Abre app.diagrams.net
  2. Elige guardar en "Google Drive" o "Este dispositivo"
  3. Arrastra formas desde el panel izquierdo
  4. Conecta formas con flechas arrastrando desde los bordes
  5. Doble clic en cualquier elemento para editar texto
  6. Exporta con Archivo → Exportar → PNG/PDF/SVG

Uso con IA → XML (avanzado)

  1. Pide al agente: "genera el XML para Draw.io de este proceso"
  2. Copia el XML que te devuelve
  3. En Draw.io: Extras → Edit Diagram
  4. Pega el XML y haz clic en OK
  5. El diagrama aparece listo para editar
  6. Ajusta posiciones arrastrando los nodos

XML de Draw.io generado por IA

Este es el formato XML que espera Draw.io. Puedes pedirle a ChatGPT o Claude que genere esto:

<mxGraphModel> <root> <mxCell id="0"/> <mxCell id="1" parent="0"/> <!-- Nodo inicio --> <mxCell id="2" value="Inicio" style="ellipse;fillColor=#d5e8d4;strokeColor=#82b366;" vertex="1" parent="1"> <mxGeometry x="160" y="40" width="120" height="60" as="geometry"/> </mxCell> <!-- Nodo proceso --> <mxCell id="3" value="Registrar matrícula" style="rounded=1;fillColor=#dae8fc;strokeColor=#6c8ebf;" vertex="1" parent="1"> <mxGeometry x="140" y="140" width="160" height="60" as="geometry"/> </mxCell> <!-- Flecha de inicio a proceso --> <mxCell id="4" edge="1" source="2" target="3" parent="1"> <mxGeometry relative="1" as="geometry"/> </mxCell> </root> </mxGraphModel>
05 · Mind Maps

Mapas mentales con IA

Las herramientas modernas generan mapas mentales completos en segundos desde un texto o tema. Perfectas para resumir lecturas, planificar proyectos y preparar clases.

⚡

Napkin AI — El más rápido

Pega cualquier texto y genera automáticamente diagramas, mapas mentales y visualizaciones. Sin prompts necesarios.

1. Ve a napkin.ai 2. Pega tu texto (apuntes, resumen, etc.) 3. Haz clic en el ícono ✦ que aparece 4. Elige el tipo de diagrama 5. Exporta a PNG o SVG
→ napkin.ai
🧊

Coggle — Colaborativo

Mapas mentales colaborativos en el navegador. Gratis para 3 diagramas, ilimitados en modo solo. Interfaz muy intuitiva.

→ coggle.it

08 · Anatomía del prompt

El marco H · T · E · F para diagramas

Cualquier prompt para generar un diagrama con IA tiene 4 partes. Si incluyes las cuatro, obtienes el diagrama correcto a la primera.

H
Herramienta

¿En qué formato?
Mermaid · PlantUML · Draw.io XML

T
Tipo

¿Qué diagrama?
Flowchart · Gantt · Clases · Mindmap

E
Elementos

¿Qué incluir?
Actores · Nodos · Entidades · Pasos

F
Formato

¿Cómo entregarlo?
Idioma · Límite · Solo código

Fórmula:
[H] Genera código Mermaid flowchart TD · [T] para el proceso de matrícula · [E] con nodos: Estudiante, Tesorería, Secretaría y las decisiones ¿Pago OK? y ¿Hay cupo? · [F] etiquetas en español, máximo 10 nodos, solo el bloque de código sin explicaciones.
