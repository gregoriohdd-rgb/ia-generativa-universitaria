01 · Los 3 grandes agentes

Antigravity, Claude Code y Codex

Las tres plataformas de agentes de código más completas en 2026, desarrolladas por Google, Anthropic y OpenAI respectivamente.

🚀

Google

Antigravity

Plataforma de desarrollo agentivo de Google, impulsada por los modelos Gemini 4. Permite correr múltiples agentes en paralelo sobre Git worktrees aislados, con una app de escritorio, CLI, extensiones de IDE y SDK en Python.

🖥 App escritorio ⌨ CLI (agy) 🧩 IDE (VS Code, JetBrains, Zed, Xcode) 🐍 SDK Python
⚡Agentes paralelos en Git worktrees aislados
🧠Gemini 4 Neon, Carbon, Argon, Hydrogen
🔒Permisos granulares y VPC Enterprise
🔌MCP, Skills, Rules y hooks personalizables
⏰Tareas programadas (cron) en segundo plano
🔁Bucles de verificación automáticos
Gemini 4 & 3.8ParaleloMulti-IDEEnterprise
↗ antigravity.google
🟠

Anthropic

Claude Code

Agente de código terminal-first de Anthropic. Lee toda la codebase, edita archivos en múltiples lenguajes, corre comandos de shell, crea commits y abre PRs en GitHub/GitLab. Destaca en razonamiento complejo.

⌨ CLI (claude) 🧩 VS Code 🖥 App escritorio 🌐 Browser
📁Lee toda la codebase y edita múltiples archivos
🔀Commits, branches y pull requests automáticos
📄CLAUDE.md para instrucciones persistentes
🤖Subagentes en paralelo y flujos dinámicos
🔌MCP, Skills, Hooks y Plugin marketplace
🔬Code intelligence (LSP) para navegación precisa
Claude 4+Terminal-firstGit integradoMulti-agente
↗ code.claude.com
🟢

OpenAI

Codex CLI

Agente de código terminal de OpenAI. Opera en un sandbox de seguridad configurable que restringe filesystem y red. Excelente para revisión de código, CI/CD y pipelines de automatización con modo headless.

⌨ CLI (codex) 🧩 VS Code / Cursor 🖥 App escritorio ☁ Codex Web
🔒Sandbox OS-enforced: filesystem + red configurable
🔍Revisión de cambios sin modificar el working tree
🤖Subagentes especializados por dominio
⚙Modo headless para CI/CD y scripts
🌐Búsqueda web en vivo durante la sesión
🔌MCP y perfiles de permisos por proyecto
o3 / o4-miniSandboxCI/CDHeadless
↗ github.com/openai/codex

Comparación detallada: flujo de trabajo

Instalación rápida

curl -fsSL https://antigravity.google/cli/install.sh | bash # O instala desde antigravity.google/download # Inicio de sesión agy auth login # Iniciar sesión interactiva agy

SDK Python

pip install google-antigravity # O con uv uv add google-antigravity

Capacidades destacadas

  • Modos: Local (carpeta activa) o New worktree (Git worktree aislado)
  • Gestiona múltiples agentes desde la Antigravity App como centro de control
  • Tareas programadas (cron) que corren sin que tu computadora esté encendida
  • Verificación visual con planes de implementación, diffs unificados y grabaciones de sesiones de navegador
  • Integración nativa con VS Code, JetBrains, Xcode, Zed, Eclipse y Visual Studio
Modelos disponibles: Gemini 4 Neon · Gemini 4 Carbon · Gemini 4 Argon · Gemini 4 Hydrogen · Gemini 3.8 Flash · Gemini 3.1 Pro

Instalación rápida

npm install -g @anthropic-ai/claude-code # Iniciar sesión claude auth login # Inicio en tu repositorio cd mi-proyecto claude

Ejemplo de tarea

claude "escribe pruebas para el módulo auth, ejecútalas y corrige los errores" claude "crea un PR con mis cambios y redacta una descripción detallada"

Capacidades destacadas

  • CLAUDE.md: archivo en la raíz del proyecto con estándares de código, librerías preferidas y reglas que Claude sigue en cada sesión
  • Skills: workflows reutilizables del equipo como /review-pr o /deploy-staging
  • Hooks: ejecuta comandos antes/después de acciones (ej. ESLint después de cada edición)
  • Integración con GitHub Actions y GitLab CI/CD para revisión automatizada
  • Artifacts: publica la salida de la sesión como página web interactiva privada
Composable: sigue la filosofía Unix. Puedes componer Claude Code con pipes, scripts y CI pipelines.

Instalación rápida

npm install -g @openai/codex # Inicio de sesión codex auth login # Iniciar en tu repositorio cd mi-proyecto codex

Modo headless (CI/CD)

# Revisar cambios antes de un commit codex review --changes # Ejecutar tarea no interactiva codex exec -p "actualiza las dependencias desactualizadas y corre los tests"

El sandbox de seguridad

Por defecto, el sandbox de Codex:

  • ✅ Permite escrituras dentro del workspace
  • ✅ Permite lecturas amplias del filesystem (librerías, SDKs)
  • 🔒 Deshabilita el acceso a red por defecto
  • 🔒 Mantiene .git y .codex en modo solo lectura
Perfiles de permisos: configura exactamente qué carpetas y qué acceso a red tiene el agente por proyecto. Ideal para entornos corporativos.
02 · Otras herramientas destacadas

El ecosistema completo

Más allá de los tres grandes, existe un ecosistema rico de herramientas especializadas para distintos flujos de trabajo.

🐙

GitHub Copilot

Microsoft / GitHub · desde 2021

El asistente de código más usado del mundo. Autocompletado inteligente, chat con la codebase, Copilot Workspace para tareas multi-archivo y revisión automática de PRs.

  • Integración nativa en VS Code, JetBrains, Neovim, CLI
  • Copilot Chat: preguntas sobre cualquier parte del código
  • Revisión automática de pull requests
  • Plan gratuito disponible para estudiantes
Gratis (estudiantes)Pro desde $10/mes
↗ github.com/features/copilot
🖱

Cursor

Anysphere · editor IA-nativo

Editor de código construido sobre VS Code con IA integrada profundamente. El chat conoce toda tu codebase, el Composer reescribe múltiples archivos y el Tab predice el siguiente bloque de código.

  • Funciona con Claude, GPT-4o, Gemini (tú eliges)
  • Composer: edita múltiples archivos a la vez
  • Tab: autocompletado que predice bloques completos
  • Agentes en paralelo desde el IDE
Gratis (limitado)Pro $20/mes
↗ cursor.com

Devin

Cognition AI · "El primer ingeniero IA"

El primer agente autónomo que actúa como un ingeniero de software completo: planifica, busca documentación, escribe código, depura errores y hace deployment. Opera de forma asíncrona.

  • Puede trabajar durante horas sin intervención humana
  • Integración con Slack (asígnale tareas desde mensajes)
  • Revisa y corrige sus propios errores en bucle
  • Ideal para tareas largas y bien definidas
Enterprise

  • Cascade: modo agentivo que combina acciones y chat
  • Supercomplete: autocompletado ultra-contextual
  • Gratuito con un generoso tier de uso

04 · ¿Cuándo usar cuál?

Guía de elección según la tarea

No existe "la mejor herramienta". Existe la herramienta correcta para cada situación.

🎓 Estoy aprendiendo a programar

→ GitHub Copilot · Cursor · Replit Agent

Integración suave en el editor, sugerencias en tiempo real y un entorno que no requiere configuración previa (Replit).

🔨 Proyecto grande y complejo

→ Google Antigravity · Claude Code

Ambos razonan sobre toda la codebase, editan múltiples archivos, lanzan pruebas y trabajan en paralelo sobre ramas independientes.

🔁 CI/CD y automatización

→ Codex CLI · Claude Code · Antigravity CLI

Los tres ofrecen modo headless y se pueden integrar en pipelines de GitHub Actions o GitLab CI con un solo comando.

🎨 Crear una interfaz rápido

→ v0 · Bolt · Replit Agent

Del texto a un componente visual en segundos. Perfectos para prototipos, dashboards y MVPs sin configuración de entorno.

🏢 Entorno corporativo con seguridad estricta

→ Codex CLI · Antigravity Enterprise

Codex ofrece sandbox OS-enforced. Antigravity Enterprise incluye VPC Service Controls. Ambos permiten definir exactamente qué puede tocar el agente.

🤝 Delegar una tarea larga sin supervisión

→ Devin · Antigravity (cron) · Claude Code (background)

Devin trabaja de forma asíncrona por horas. Antigravity puede programar tareas que corren incluso con la computadora apagada.

💸 Sin presupuesto (gratis o casi)

→ Aider · Windsurf · GitHub Copilot (estudiantes)

Aider es completamente open source. Windsurf tiene un generoso tier gratuito. Copilot es gratis para estudiantes verificados.

⚙ Integrar con mis propias herramientas (MCP)

→ Antigravity · Claude Code · Codex CLI · Cursor

Los cuatro soportan el Model Context Protocol (MCP), que conecta el agente con bases de datos, APIs, Slack, Jira y cualquier servicio externo.

05 · En la universidad

Uso académico responsable

Los agentes de código multiplican la productividad, pero su uso en contextos académicos requiere criterios claros.

✅ Usos recomendados

  • Explorar y entender código existente ("¿qué hace esta función?")
  • Generar código de prueba (tests unitarios) para funciones que ya escribiste
  • Detectar errores y vulnerabilidades en tu propio código
  • Automatizar tareas repetitivas: formateo, refactoring, documentación
  • Prototipado rápido de ideas para después implementarlas tú
  • Aprender explicando: "¿por qué falla este código?"

⚠ Precauciones importantes

  • Verifica siempre el código generado antes de ejecutarlo en producción
  • Los agentes pueden inventar funciones de librerías que no existen ("alucinaciones de API")
  • No copies código generado en entregas académicas sin entenderlo primero
  • Nunca incluyas credenciales, tokens ni contraseñas en el contexto del agente
  • Consulta la política de tu universidad sobre el uso de IA en trabajos académicos
🔒 Datos confidenciales: Nunca envíes a un agente de código información personal de estudiantes, datos de sistemas institucionales o credenciales de acceso. Trabaja siempre con datos ficticios o anonimizados en entornos de prueba.
💡 Regla de oro para aprender: Un agente de código es un tutor, no un sustituto. Úsalo para entender el "¿por qué?" detrás del código que genera. Si no puedes explicar lo que hizo el agente, aún no lo has aprendido.

¿Cómo presentar estas herramientas a tus estudiantes?

1. Demostraciones en vivo

Muestra en tiempo real cómo el agente lee un proyecto, detecta un error y propone una solución. Usa código ficticio.

2. Comparar con y sin IA

Asigna la misma tarea a mitad del grupo con agente y la otra mitad sin él. Compara la calidad y el tiempo invertido.

3. Pedir que expliquen el código

Después de usar el agente, el estudiante debe exponer oralmente qué hace el código. Esto valida la comprensión real.

4. Comenzar con Aider o Replit

Son gratuitos, fáciles de configurar y no requieren cuenta de pago. Perfectos para un primer contacto en clase.
