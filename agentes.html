01 · Los 3 grandes agentes

Antigravity, Claude Code y Codex

Las tres plataformas de agentes de código más completas en 2026, desarrolladas por Google, Anthropic y OpenAI respectivamente.

🚀

Google

Antigravity

Plataforma de desarrollo agentivo de Google, impulsada por los modelos Gemini 4. Permite correr múltiples agentes en paralelo sobre Git worktrees aislados, con una app de escritorio, CLI, extensiones de IDE y SDK en Python.

🖥 App escritorio ⌨ CLI (agy) 🧩 IDE (VS Code, JetBrains, Zed, Xcode) 🐍 SDK Python
⚡Agentes paralelos en Git worktrees aislados
🧠Gemini 4 Neon, Carbon, Argon, Hydrogen
🔒Permisos granulares y VPC Enterprise
🔌MCP, Skills, Rules y hooks personalizables
⏰Tareas programadas (cron) en segundo plano
🔁Bucles de verificación automáticos
Gemini 4 & 3.8ParaleloMulti-IDEEnterprise
↗ antigravity.google
🟠

Anthropic

Claude Code

Agente de código terminal-first de Anthropic. Lee toda la codebase, edita archivos en múltiples lenguajes, corre comandos de shell, crea commits y abre PRs en GitHub/GitLab. Destaca en razonamiento complejo.

⌨ CLI (claude) 🧩 VS Code 🖥 App escritorio 🌐 Browser
📁Lee toda la codebase y edita múltiples archivos
🔀Commits, branches y pull requests automáticos
📄CLAUDE.md para instrucciones persistentes
🤖Subagentes en paralelo y flujos dinámicos
🔌MCP, Skills, Hooks y Plugin marketplace
🔬Code intelligence (LSP) para navegación precisa
Claude 4+Terminal-firstGit integradoMulti-agente
↗ code.claude.com
🟢

OpenAI

Codex CLI

Agente de código terminal de OpenAI. Opera en un sandbox de seguridad configurable que restringe filesystem y red. Excelente para revisión de código, CI/CD y pipelines de automatización con modo headless.

⌨ CLI (codex) 🧩 VS Code / Cursor 🖥 App escritorio ☁ Codex Web
🔒Sandbox OS-enforced: filesystem + red configurable
🔍Revisión de cambios sin modificar el working tree
🤖Subagentes especializados por dominio
⚙Modo headless para CI/CD y scripts
🌐Búsqueda web en vivo durante la sesión
🔌MCP y perfiles de permisos por proyecto
o3 / o4-miniSandboxCI/CDHeadless
↗ github.com/openai/codex

Comparación detallada: flujo de trabajo

Instalación rápida

curl -fsSL https://antigravity.google/cli/install.sh | bash # O instala desde antigravity.google/download # Inicio de sesión agy auth login # Iniciar sesión interactiva agy

SDK Python

pip install google-antigravity # O con uv uv add google-antigravity

Capacidades destacadas

  • Modos: Local (carpeta activa) o New worktree (Git worktree aislado)
  • Gestiona múltiples agentes desde la Antigravity App como centro de control
  • Tareas programadas (cron) que corren sin que tu computadora esté encendida
  • Verificación visual con planes de implementación, diffs unificados y grabaciones de sesiones de navegador
  • Integración nativa con VS Code, JetBrains, Xcode, Zed, Eclipse y Visual Studio
Modelos disponibles: Gemini 4 Neon · Gemini 4 Carbon · Gemini 4 Argon · Gemini 4 Hydrogen · Gemini 3.8 Flash · Gemini 3.1 Pro

Instalación rápida

npm install -g @anthropic-ai/claude-code # Iniciar sesión claude auth login # Inicio en tu repositorio cd mi-proyecto claude

Ejemplo de tarea

claude "escribe pruebas para el módulo auth, ejecútalas y corrige los errores" claude "crea un PR con mis cambios y redacta una descripción detallada"

Capacidades destacadas

  • CLAUDE.md: archivo en la raíz del proyecto con estándares de código, librerías preferidas y reglas que Claude sigue en cada sesión
  • Skills: workflows reutilizables del equipo como /review-pr o /deploy-staging
  • Hooks: ejecuta comandos antes/después de acciones (ej. ESLint después de cada edición)
  • Integración con GitHub Actions y GitLab CI/CD para revisión automatizada
  • Artifacts: publica la salida de la sesión como página web interactiva privada
Composable: sigue la filosofía Unix. Puedes componer Claude Code con pipes, scripts y CI pipelines.

Instalación rápida

npm install -g @openai/codex # Inicio de sesión codex auth login # Iniciar en tu repositorio cd mi-proyecto codex

Modo headless (CI/CD)

# Revisar cambios antes de un commit codex review --changes # Ejecutar tarea no interactiva codex exec -p "actualiza las dependencias desactualizadas y corre los tests"

El sandbox de seguridad

Por defecto, el sandbox de Codex:

  • ✅ Permite escrituras dentro del workspace
  • ✅ Permite lecturas amplias del filesystem (librerías, SDKs)
  • 🔒 Deshabilita el acceso a red por defecto
  • 🔒 Mantiene .git y .codex en modo solo lectura
Perfiles de permisos: configura exactamente qué carpetas y qué acceso a red tiene el agente por proyecto. Ideal para entornos corporativos.
02 · Otras herramientas destacadas

El ecosistema completo

Más allá de los tres grandes, existe un ecosistema rico de herramientas especializadas para distintos flujos de trabajo.

🐙

GitHub Copilot

Microsoft / GitHub · el más usado del mundo · desde 2021

El asistente de IA más extendido del mundo para programar. Funciona dentro del editor como un colega invisible: completa código, responde preguntas sobre el proyecto, revisa PRs y puede actuar como agente en tareas multi-archivo.

🔑 Capacidades principales

  • Autocompletado inline: sugiere la siguiente línea o bloque completo mientras escribes
  • Copilot Chat: conversa sobre cualquier archivo, función o error del proyecto
  • Copilot Edits: propone cambios en múltiples archivos a la vez (modo agente)
  • Revisión de PRs: analiza automáticamente pull requests antes del merge
  • CLI: usa gh copilot suggest desde la terminal para obtener comandos
  • Modelos: GPT-4o, Claude Sonnet, Gemini (tú eliges en la configuración)

🏛 Útil en la universidad para

  • Ayudar a estudiantes a entender errores sin darte la respuesta directa
  • Generar código de ejemplo para clases de programación
  • Crear scripts para procesar listas de alumnos o notas (en datos ficticios)
  • Documentar automáticamente funciones y módulos
  • Sugerir mejoras de estilo y eficiencia en el código estudiantil
🎓 Gratis para estudiantes: solicítalo en education.github.com con tu correo universitario. Incluye Copilot Pro y otros beneficios.

Aider

Paul Gauthier · 100% open source · el mejor agente gratuito

El agente de código open source más completo y potente. Corre en tu terminal, edita múltiples archivos, hace commits automáticos y funciona con más de 100 modelos (incluyendo modelos locales sin costo de API).

🔑 Capacidades principales

  • Repo map: construye un mapa de toda la arquitectura del proyecto para entender las dependencias
  • Multi-archivo: edita simultáneamente todos los archivos necesarios para completar una tarea
  • Git nativo: cada cambio genera un commit automático con mensaje descriptivo (fácil de revertir)
  • +100 modelos: GPT-4o, Claude, Gemini, DeepSeek, o modelos locales con Ollama
  • Modo arquitecto: usa un modelo para planificar y otro para ejecutar los cambios
  • Voz: dicta las instrucciones con el micrófono (--voice)

💡 Ejemplos de uso rápido

# Iniciar en un proyecto cd mi-proyecto aider --model claude-sonnet-4-5 # Pedir una tarea completa > Agrega validación de email al formulario de registro y escribe los tests # Con modelo local (sin costo) aider --model ollama/llama3.2 # Modo arquitecto (más inteligente) aider --architect
💡 Consejo para docentes: Aider es ideal para clase porque todos los cambios quedan en commits Git. Puedes revisar exactamente qué hizo el agente con git log.

04 · ¿Cuándo usar cuál?

Guía de elección según la tarea

No existe "la mejor herramienta". Existe la herramienta correcta para cada situación.

🎓 Estoy aprendiendo a programar

→ GitHub Copilot · Cursor · Replit Agent

Integración suave en el editor, sugerencias en tiempo real y un entorno que no requiere configuración previa (Replit).

🔨 Proyecto grande y complejo

→ Google Antigravity · Claude Code

Ambos razonan sobre toda la codebase, editan múltiples archivos, lanzan pruebas y trabajan en paralelo sobre ramas independientes.

🔁 CI/CD y automatización

→ Codex CLI · Claude Code · Antigravity CLI

Los tres ofrecen modo headless y se pueden integrar en pipelines de GitHub Actions o GitLab CI con un solo comando.

🎨 Crear una interfaz rápido

→ v0 · Bolt · Replit Agent

Del texto a un componente visual en segundos. Perfectos para prototipos, dashboards y MVPs sin configuración de entorno.

🏢 Entorno corporativo con seguridad estricta

→ Codex CLI · Antigravity Enterprise

Codex ofrece sandbox OS-enforced. Antigravity Enterprise incluye VPC Service Controls. Ambos permiten definir exactamente qué puede tocar el agente.

🤝 Delegar una tarea larga sin supervisión

→ Devin · Antigravity (cron) · Claude Code (background)

Devin trabaja de forma asíncrona por horas. Antigravity puede programar tareas que corren incluso con la computadora apagada.

💸 Sin presupuesto (gratis o casi)

→ Aider · Windsurf · GitHub Copilot (estudiantes)

Aider es completamente open source. Windsurf tiene un generoso tier gratuito. Copilot es gratis para estudiantes verificados.

⚙ Integrar con mis propias herramientas (MCP)

→ Antigravity · Claude Code · Codex CLI · Cursor

Los cuatro soportan el Model Context Protocol (MCP), que conecta el agente con bases de datos, APIs, Slack, Jira y cualquier servicio externo.

06 · Instalación paso a paso

Cómo instalar las herramientas más accesibles

Guías detalladas para las cuatro herramientas más fáciles de empezar — sin experiencia previa en DevOps.

GitHub Copilot en VS Code

1
Crea una cuenta en GitHub

Ve a github.com → Sign up → usa tu correo universitario.

2
Activa Copilot gratuito

Ve a github.com/settings/copilot → elige el plan Free (2000 completados/mes) o solicita el plan estudiantil.

3
Para estudiantes: acceso gratuito completo

Ve a education.github.com/students → verifica con tu correo o carnet universitario → obtienes Copilot Pro gratis.

4
Instala VS Code

Descarga desde code.visualstudio.com e instala como cualquier programa.

5
Instala la extensión GitHub Copilot

En VS Code: panel izquierdo → ícono de extensiones (cuadrados) → busca "GitHub Copilot" → Install → Sign in con tu cuenta GitHub.

6
¡Listo! Prueba estas funciones

Escribe código y verás sugerencias en gris. Tab para aceptar. Ctrl+I para editar en línea. Ctrl+Alt+I para abrir el chat.

Comandos útiles del chat

# En el chat de Copilot (Ctrl+Alt+I): /explain → explica el código seleccionado /fix → propone una corrección al error /tests → genera pruebas unitarias /doc → escribe la documentación /simplify → simplifica el código # En la terminal integrada: gh copilot suggest "cómo listar archivos por fecha" gh copilot explain "git rebase -i HEAD~3"
Modelos disponibles en Copilot: puedes cambiar el modelo en el chat haciendo clic en el nombre del modelo. Opciones: GPT-4o, Claude Sonnet, Gemini Flash y más.
Truco para docentes: instala también la extensión "GitHub Copilot Chat" para tener el panel de chat lateral siempre visible mientras enseñas.

Aider: instalación en 3 pasos

1
Instala Python 3.9 o superior

Descarga desde python.org/downloads. En Windows: marca "Add Python to PATH" al instalar. Verifica con python --version

2
Instala Aider
# Método recomendado (instalador oficial) python -m pip install aider-install aider-install # Alternativa directa pip install aider-chat
3
Configura tu API key (elige uno)
# Windows (PowerShell) — elige un modelo: $env:ANTHROPIC_API_KEY="tu-clave-aqui" # Claude $env:OPENAI_API_KEY="tu-clave-aqui" # GPT-4o $env:GEMINI_API_KEY="tu-clave-aqui" # Gemini # O sin costo con modelo local (Ollama): # 1. Instala Ollama desde ollama.com # 2. ollama pull llama3.2 # 3. aider --model ollama/llama3.2
4
Inicia Aider en tu proyecto
cd mi-proyecto aider # modelo por defecto aider --model gemini/gemini-2.0-flash # Gemini gratuito

Uso dentro de Aider

# Una vez dentro del chat interactivo: # Agregar archivos al contexto /add app.py utils.py # Pedir una tarea > Agrega una función que calcule el promedio de una lista de notas y escribe sus pruebas unitarias # Ver los archivos en contexto /ls # Deshacer el último cambio /undo # Ver el diff del último cambio /diff # Cambiar modelo en medio de sesión /model claude-sonnet-4-5 # Salir /exit
🌟 Mejor modelo gratuito: usa --model gemini/gemini-2.0-flash con una API key de Google AI Studio (gratis). Límite generoso para uso académico.

Cursor: instalación en 4 pasos

1
Descarga Cursor

Ve a cursor.com → Download → elige tu sistema operativo (Windows/Mac/Linux). Es un instalador estándar.

2
Instala y abre

Instala como cualquier aplicación. Al abrir por primera vez, te pregunta si quieres importar tu configuración de VS Code — ¡acepta! Tendrás tus extensiones y temas automáticamente.

3
Crea una cuenta y elige modelo

Regístrate con tu correo → elige el plan gratuito → en la barra inferior selecciona el modelo: Claude, GPT-4o o Gemini.

4
Abre tu proyecto

File → Open Folder → selecciona tu carpeta de proyecto. Cursor indexa automáticamente todos los archivos.

Atajos clave de Cursor

# Chat con toda la codebase: Ctrl + L → abre el panel de chat @archivo.py → incluye un archivo en el contexto @carpeta/ → incluye toda una carpeta #función → referencia una función específica # Edición inteligente: Ctrl + K → editar el código seleccionado con instrucción en lenguaje natural Tab → acepta sugerencia de autocompletado # Composer (edita múltiples archivos): Ctrl + Shift + I → abre Composer Describe la tarea y edita todo el proyecto a la vez # Agente autónomo: En el Composer → activa "Agent" mode para que el agente ejecute comandos también
Para clases: Cursor es el editor preferido por desarrolladores IA. Muéstraselo a tus estudiantes como el estándar de la industria actual.

Windsurf: instalación en 4 pasos

1
Descarga Windsurf

Ve a windsurf.com → Download → elige tu sistema operativo. Instalador estándar como cualquier app.

2
Regístrate gratuitamente

Abre Windsurf → Sign Up → usa tu correo (funciona con correo universitario). El plan gratuito incluye 25 créditos "premium" diarios + uso ilimitado con modelos básicos.

3
Importa configuración de VS Code

Windsurf detecta automáticamente VS Code y te ofrece importar temas, extensiones y atajos. Recomendado si ya usas VS Code.

4
Abre tu proyecto y usa Cascade

File → Open Folder → Ctrl+L para abrir Cascade (el chat agentivo). Es más que un chat: observa, actúa y ejecuta como un colega de trabajo.

Lo que hace especial a Windsurf

🌊 Cascade: el agente que "fluye"

A diferencia de los chats tradicionales, Cascade no solo responde: observa el estado del proyecto en tiempo real, actúa sobre los archivos y verifica sus propias acciones sin que tengas que pedírselo.

⚡ Supercomplete

El autocompletado de Windsurf no solo completa la línea actual — predice bloques de código considerando el contexto de todo el archivo y el flujo lógico del programa.

📊 Créditos y planes

Gratis: 25 créditos premium/día + ilimitados con modelos Codeium propios. Pro ($15/mes): 500 créditos + acceso a Claude y GPT-4o.

07 · Gestión universitaria

Agentes de IA en la administración universitaria

Estos agentes no solo sirven para programar. Son herramientas potentes para automatizar, analizar y gestionar procesos administrativos — sin escribir una sola línea de código.

📌 Punto de partida: Para usar agentes en gestión universitaria, basta con tener instalado Claude Code, Codex CLI o Cursor y una carpeta con tus documentos de trabajo (siempre con datos ficticios o anonimizados).
📊

Análisis de datos académicos

El agente lee archivos CSV con calificaciones o asistencias (ficticias) y genera reportes automáticos con estadísticas, gráficos e interpretación.

Prompt de ejemplo: "Lee el archivo notas.csv con las calificaciones de 50 estudiantes ficticios. Genera: 1. Estadísticas por asignatura (media, desv. típica) 2. Identifica qué asignaturas tienen más desaprobados 3. Crea un reporte en formato HTML listo para imprimir"
📅

Automatización de cronogramas

Genera horarios de clases, calendarios de evaluaciones o cronogramas de actividades a partir de restricciones que describes en lenguaje natural.

Prompt de ejemplo: "Tengo 6 asignaturas ficticias, 3 aulas disponibles y docentes con horarios de disponibilidad en horario.txt. Crea un cronograma semanal en HTML sin conflictos de aulas ni de docentes"
📋

Revisión y mejora de reglamentos

El agente lee un documento de reglamento, detecta inconsistencias, artículos ambiguos y sugiere mejoras de redacción.

Prompt de ejemplo: "Lee el archivo reglamento_matricula_ejemplo.txt. Identifica: 1) artículos con lenguaje ambiguo, 2) posibles contradicciones entre artículos, 3) términos no definidos. Propón mejoras de redacción manteniendo el contenido original"
📬

Generación masiva de comunicados

A partir de una plantilla y una lista de datos, el agente genera docenas de comunicados personalizados en segundos.

Prompt de ejemplo: "Lee lista_estudiantes_ficticios.csv con columnas: nombre, seccion, nota_final. Genera un archivo HTML con un comunicado individual para cada estudiante usando la plantilla en carta_base.txt. Separa los aprobados de los desaprobados"
🔍

Auditoría de procesos

El agente mapea un proceso universitario documentado y encuentra cuellos de botella, pasos redundantes y puntos de mejora.

Prompt de ejemplo: "Lee proceso_admision_ficticio.txt que describe el flujo de admisión de 12 pasos. Identifica: 1) pasos que pueden hacerse en paralelo, 2) pasos manuales que podrían automatizarse, 3) puntos de fallo más probables. Dibuja el nuevo flujo optimizado en ASCII"
🤖

Crear asistentes virtuales institucionales

El agente lee los documentos de tu institución (ficticios) y construye el código de un chatbot básico que responde preguntas frecuentes.

Prompt de ejemplo: "Usando el archivo faq_institucional_ejemplo.txt, crea una página web HTML con un chatbot que responda preguntas frecuentes sobre matrícula. Usa JavaScript puro, sin librerías externas. El chatbot busca la pregunta más similar y devuelve la respuesta correspondiente"
🔑 Regla de oro: todos los ejemplos anteriores usan datos ficticios. Nunca pongas datos reales de estudiantes, docentes o documentos confidenciales en ningún agente de IA.
08 · Elaboración de documentos

Crear documentos universitarios con agentes IA

Los agentes de código pueden generar, revisar y dar formato a documentos técnicos y administrativos con una calidad notable. Aquí los tipos más útiles con prompts listos para usar.

Acta de reunión institucional

El agente transforma notas desordenadas de una reunión en un acta formal estructurada, con acuerdos, responsables y fechas.

Eres el secretario académico de una universidad. A continuación te paso las notas de la reunión del Consejo de Facultad del [FECHA FICTICIA]. NOTAS: [pega aquí tus notas tal como las tomaste] Genera el acta formal con: 1. Encabezado institucional 2. Lista de asistentes (ficticios) 3. Orden del día 4. Desarrollo de cada punto con acuerdos 5. Cuadro de compromisos: responsable, acción y plazo 6. Cierre y firmas (con nombres ficticios) Formato: Markdown listo para convertir a Word.

Workflow recomendado

1

Uso académico responsable

Los agentes de código multiplican la productividad, pero su uso en contextos académicos requiere criterios claros.

✅ Usos recomendados

  • Explorar y entender código existente ("¿qué hace esta función?")
  • Generar código de prueba (tests unitarios) para funciones que ya escribiste
  • Detectar errores y vulnerabilidades en tu propio código
  • Automatizar tareas repetitivas: formateo, refactoring, documentación
  • Prototipado rápido de ideas para después implementarlas tú
  • Aprender explicando: "¿por qué falla este código?"

⚠ Precauciones importantes

  • Verifica siempre el código generado antes de ejecutarlo en producción
  • Los agentes pueden inventar funciones de librerías que no existen ("alucinaciones de API")
  • No copies código generado en entregas académicas sin entenderlo primero
  • Nunca incluyas credenciales, tokens ni contraseñas en el contexto del agente
  • Consulta la política de tu universidad sobre el uso de IA en trabajos académicos
🔒 Datos confidenciales: Nunca envíes a un agente de código información personal de estudiantes, datos de sistemas institucionales o credenciales de acceso. Trabaja siempre con datos ficticios o anonimizados en entornos de prueba.
💡 Regla de oro para aprender: Un agente de código es un tutor, no un sustituto. Úsalo para entender el "¿por qué?" detrás del código que genera. Si no puedes explicar lo que hizo el agente, aún no lo has aprendido.

¿Cómo presentar estas herramientas a tus estudiantes?

1. Demostraciones en vivo

Muestra en tiempo real cómo el agente lee un proyecto, detecta un error y propone una solución. Usa código ficticio.

2. Comparar con y sin IA

Asigna la misma tarea a mitad del grupo con agente y la otra mitad sin él. Compara la calidad y el tiempo invertido.

3. Pedir que expliquen el código

Después de usar el agente, el estudiante debe exponer oralmente qué hace el código. Esto valida la comprensión real.

4. Comenzar con Aider o Replit

Son gratuitos, fáciles de configurar y no requieren cuenta de pago. Perfectos para un primer contacto en clase.
